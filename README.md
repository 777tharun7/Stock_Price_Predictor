# Stock Price Predictor

An educational project exploring forecasting from historical market data.

> **Disclaimer:** This project is not investment advice. Historical model performance does not guarantee future performance.

## Evaluation workflow
1. Specify the asset, target variable, forecast horizon, and prediction frequency.
2. Record the data provider, date range, retrieval date, and usage restrictions.
3. Inspect missing timestamps, duplicates, and adjusted versus unadjusted prices.
4. Use chronological train, validation, and test periods.
5. Prevent look-ahead leakage by ensuring every feature uses information available at prediction time.
6. Compare with a suitable naive baseline, such as the last-observed-price forecast.
7. Report out-of-sample MAE and RMSE and plot actual versus predicted values.
